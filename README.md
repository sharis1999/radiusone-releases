# RadiusOne releases

Designed & developed by Sardar Haris

Signed RadiusOne releases (installer, images, production configuration). Newest: **0.1.0**.

Install on a fresh Ubuntu 22.04/24.04, Debian 12 or Rocky/Alma 9 server (it asks for the domain and the network):

```sh
curl -fsSL https://github.com/sharis1999/radiusone-releases/releases/latest/download/install.sh | sudo sh
```

Updates: panel > Tools > System update.
